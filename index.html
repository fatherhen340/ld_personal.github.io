03 / PUBLISHING

连接 GitHub

发布操作会通过 GitHub API 直接提交到你的仓库。令牌只保存在当前浏览器的 localStorage 中，不会发送到其他服务器。

尚未连接。填写后先测试连接，再保存。

HOW TO CONNECT / 连接步骤

  1. 把站点文件上传到 GitHub 仓库，并开启 GitHub Pages。
  2. 在 GitHub 的 Settings → Developer settings → Personal access tokens → Fine-grained tokens 创建令牌。
  3. 仓库访问权限只选这个站点仓库，权限勾选 Contents: Read and write。
  4. 把令牌粘贴到左侧并保存。之后编辑好内容，点“发布”即可。

令牌等同于仓库写入权限，请勿提交到代码库，也不要在公共电脑上保存。如怀疑泄露，请立即在 GitHub 撤销。
